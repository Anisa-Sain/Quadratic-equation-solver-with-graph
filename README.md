# Quadratic Equation Solver (MATLAB)

A simple MATLAB script that solves a user-defined quadratic equation, plots the graph, and displays the roots clearly.  
Created for the ENGFF003 – Computer Methods Mini Project.

---

## What it does
The script works with equations of the form:

y = ax^2 + bx + c

After entering values for a, b, and c, the program:
- Determines how many roots the equation has
- Calculates the correct root(s)
- Plots the quadratic curve
- Marks and labels the roots on the graph
- Prints useful information to the MATLAB Command Window

---

## Features
- User input for coefficients a, b, and c
- Input validation and error handling
- Handles:
  - Two real roots
  - One repeated root
  - Two complex roots
- Dynamic plotting range to show all points of interest
- Clear plot labels, title, and legend
- Fully commented code for readability

---

## How to run
1. Open the `.m` file in MATLAB
2. Run the script
3. Follow the prompts in the Command Window
4. View the results and graph
